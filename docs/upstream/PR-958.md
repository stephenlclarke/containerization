# fix: preserve logical EXT4 extent ranges in reads and export

Regular file reads, long symlink reads and regular/hardlink archive export now share the inode's logical-range reader. The decoder retains extent offsets and unwritten state, validates logical order and bounds, and uses checked physical-range conversion. The reader supplies zeros for leading, interior and trailing holes and unwritten ranges, while keeping offset/EOF and partial physical-read behavior. Export additionally requires the complete inode size; truncated media cannot silently produce a successful corrupted archive. A final review identified unchecked block-to-byte arithmetic under malformed superblock geometry. The initializer now rejects block sizes above the EXT4 64 KiB limit, and a common checked conversion validates multiplication/addition, including every physical range before writing the caller buffer. The malformed-geometry RED and byte-offset boundary regressions are retained. Existing directory/tree physical-range compatibility and the reader's depth limit remain intact.

## Validation

Deterministic fixtures patch formatted inode extent records and poison the backing block of an unwritten extent. They check whole-file reads, offset Data and sentinel-buffer reads, all-hole files, full/subtree archive roundtrips and hardlink identity when the primary name is outside the subtree. Bounds regressions cover zero length, overlap/order, logical/physical overflow, device bounds, corrupt mapping rejection, and the initialized/unwritten length boundary. A truncated-media case distinguishes ordinary partial reads from strict export failure.

The unchanged `96ef6bd6a3530723353fdda783f076fc0b35598b` reader failed the sparse cases with 24 issues; a separate malformed physical-range case trapped in the old UInt32 addition. Both raw failures are retained. An initial test-only UInt32 inference compile error is retained separately and was corrected before the behavioral RED run. The fixed focused suite passed, followed by all 102 EXT4 tests with four jobs and warnings-as-errors. The final run completed in 20.820 seconds using the existing SDK scratch directory. Formatting and license checks passed. Exact commands, source/lock/toolchain identities, hashes and logs are retained in the goal's `upstream-audit/sdk-ext4-958` directory. No VM, benchmark, guest image build or release authority is claimed.
