# Pull request 68: sync Apple stdio and logging updates before 0.14.1

## Change

Pull request [#68](https://github.com/stephenlclarke/containerization/pull/68)
merges Apple `containerization` main through `fc9e638`. It brings in logger
routing from Apple pull request #843 and reusable, concurrency-bounded stdio
vsock slots from Apple pull request #855.

## Conflict resolution

The upstream stdio slot owns each pre-bound socket for the VM lifetime and the
new allocator reuses released ports. The fork continues to pre-bind its DNS
host-service port alongside the 64 stdio ports so nested virtualization can
still resolve the socket inode captured when cloud-hypervisor starts.

The pod call sites pass the new allocator while retaining the fork's configured
OCI runtime path. The fork's lifecycle, memory-reclamation, hotplug, and cleanup
changes remain otherwise unchanged.
